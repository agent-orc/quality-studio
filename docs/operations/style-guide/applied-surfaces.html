Onboard and Configure repository

The repository registry modal is the first application of this dossier. Operator evidence showed two related failures: the “+ Add repository” affordance looked broken, and Configure repository could not scroll to lower fields or its Save action.

Applied patterns

  • Add repository is a solid ghost button with one aligned leading plus.
  • Every registry field uses a label, control, and stable helper row.
  • The field region is the only internal vertical scroller.
  • Cancel and Save remain in a sticky footer outside the field scroller.
  • DOM order is unchanged, so tab focus scrolls hidden fields into view.
  • The default token cap displays as 100k and accepts 100000, 100k, and 0.1M.
  • Light and dark themes use the same geometry and behavior.
