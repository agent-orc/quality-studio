Inputs, labels, and helper text

Labels stay above controls and never depend on placeholder text. Helper text receives its own stable row below the control, starts with a capital letter, and ends with a period when it is a sentence.

Do
Existing Git repository. Relative paths resolve from the API directory.

The label and helper occupy predictable rows and describe one field.

Do not

Inline microcopy shifts labels off-register and a placeholder cannot replace a label.

Validation

Reserve the helper row for validation so the form does not jump. State the accepted shape, preserve the entered value, and connect the message with aria-describedby.

Do
Use lowercase letters, numbers, and hyphens.

The error replaces helper copy in the same location and tells the user how to recover.

Do not
Invalid!

A detached generic error does not identify the accepted input or preserve rhythm.

Selects and dropdowns

Selects use the same height, border, type size, label, helper row, and focus treatment as text inputs. Use a native select for a bounded simple list and an accessible combobox for searchable model or repository lists.

Do
Controls which quality policy the sweep applies.

The select belongs to the same field grammar as every input.

Do not

An unlabeled, undersized dropdown breaks alignment and hides its consequence.

Token-count formatting

Token quantities use a scaled unit in controls and compact operational summaries. The parser remains tolerant so pasted raw counts are valid. Preserve exact counts in exported evidence where precision matters.

Do
Tokens. Accepts 100000, 100k, or 0.1M.
tokens

The displayed value is scannable, the unit is explicit, and common pasted forms parse to the same count.

Do not
choose token or cost

An unscaled value and ambiguous helper force the operator to count digits and infer the unit.

Field-row checklist

  • Use a visible label, even when the control also has a placeholder.
  • Name units in the label or helper, not only in placeholder text.
  • Keep related rows aligned to one control width.
  • Do not mix optional notes into some labels and below other controls.
  • Allow browser focus to reveal controls inside the owning internal scroll area.
