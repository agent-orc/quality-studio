Scope, versioning, and enforcement boundary

Overrides are ordered and may change enablement, severity, autofixability, parameters, language, include globs, and exclude globs. Unknown IDs fail closed. Effective rule state participates in review policy drift. Rule IDs are never repurposed; document changes append semantic versions and dated history entries.

The quality-rules sensor only enforces violations that need little interpretation. Its results stay separate from agent findings and never determine the grade. Component reuse, API design, DI lifetime correctness, and test quality remain contextual review concerns.

Unresolved security edge case

Visible and recorded; no push block. Withholding a push and leaving a security finding unfixed merely strands the risk in a private worktree. The finding therefore remains visible in metadata, reports, and lifecycle state, but Quality Studio currently takes no enforcement action that blocks a push. Source-control gating requires a separate decision and a complete auditable ownership and exception workflow.
